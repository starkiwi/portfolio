Gameplay: Heading is a small proof-of-concept minigame. The idea is that players are stranded at sea and must identify stars in specific constellations to navigate their way back to port. They must find their heading.

Stars are instanced meshes parsed from real life data to accurately portray their positions in the sky.

From an development standpoint, the focus of this project was an web API call from Unreal Engine with HTTP and Json. Which, as my first Unreal project was quite an undertaking.

Using Unreal's FHttpRequestRef I was able to access this github repo to parse the constellation lines dataset. I reviewed many datasets to use for this project to conclude this as the best for my purposes

Data Decisions: My original thought was to use API Ninjas' stars API. However that did not include the polyline data for each constellation, only a list of stars. Furthermore, it also gave me all the stars in that constellations region, not just the ones we associate with that constellation.

Then I had found a github repo with constellation polylines listed as Yale Bright Star Catalog indexes. This was a good option. The only problem was that I would have to iterate through the Yale Bright Star Catalog to find each star in the polyline. With over 9,000 stars this was not the best method.

Perhaps the most beneficial trait of the dataset I picked was that it gave me the stars as rectangular coordinates already parsed from the stars right ascension and declination, meaning I didn't have to do that myself. I can search through to find the constellations I want parse the polylines into my own file, and plot the stars directly.

Drawing Constellations: Another challenge I faced in this project was getting the constellation to show up when the player clicked all the stars in the constellation. Each time they select a star it turns red and the code verifies if it's constellation matches that of the other selected stars.

Each star's data was in a structure listing its X and Y positions, constellation name it was apart of, and index id. Similarly constellations were in a structure with their name, a count of the number of stars in the constellation, and an array of polylines. Working with multiple arrays of structures was difficult and it took thought to make sure all the id's stayed the same so there was no indexing out-of-bounds.
